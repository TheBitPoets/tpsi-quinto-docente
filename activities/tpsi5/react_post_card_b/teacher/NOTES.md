# Note docente — React PostCard

Il laboratorio deve terminare quando lo studente sa spiegare il mapping Vue -> React.

Review:
- props read-only;
- callback props al posto di emits;
- state ownership nel parent;
- update immutabile;
- delete condizionale;
- key di dominio;
- zero fetch nel child.

Non introdurre React Router, context/global store, effects, API o realtime.
