# Note docente — milestone 8 SSR

Domande utili:

1. Perche non abbiamo creato un secondo database?
2. Perche il template vede `canDelete` ma la route chiama ancora `deleteOwned`?
3. Perche la create SSR ritorna 303?
4. Quale Content-Type riceve il server dal form?
5. Quale response contiene HTML e quale JSON?
6. Cosa cambierebbe con JavaScript disabilitato nella pagina SSR?

Non valutare SSR come migliore/peggiore della SPA: valutare la capacita di identificare trade-off e responsabilita.
