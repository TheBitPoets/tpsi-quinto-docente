# Note docente — Activity A

## Domande guida

1. Dove vedete il metodo HTTP nei due programmi?
2. Chi decide che `/api/health` deve esistere?
3. `res.json()` cambia il protocollo o e un helper?
4. Cosa fa `express.json()` che nel server nativo abbiamo scritto a mano?
5. Perche il 404 va dopo le route?
6. Cosa succederebbe se il parser JSON fosse montato dopo il router?

## Evidenza minima

Lo studente deve mostrare le tre request su entrambi i server e un `MAPPING.md` coerente.

## Non valutare come obiettivo principale

- stile del codice;
- memorizzazione delle API Express;
- dettagli profondi dell'event loop.

L'obiettivo e il passaggio **protocollo -> astrazione framework**.
