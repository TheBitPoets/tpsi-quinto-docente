# Note docente — React translation microscope

Obiettivo: far riconoscere concetti gia posseduti.

Non trasformare la lezione in una panoramica completa di React Hooks.

Punti da enfatizzare:
- `useState` e il nuovo vocabolario per un problema gia noto;
- derived value non significa `useMemo`;
- JSX e JavaScript, non una seconda variante di HTML;
- `StrictMode` e presente nella reference, ma non aprire qui il tema completo degli effetti;
- nessun API/backend/realtime: il confronto deve restare isolato.
