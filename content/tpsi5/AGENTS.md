# Istruzioni per le dispense TPSI5

Prima di creare o modificare una lezione in questa directory, leggere integralmente `STYLE_GUIDE.md`.

Tutte le dispense classroom-facing devono seguire lo standard HTML/Markdown documentato nella guida:

- titoli Markdown per anchor e indice;
- paragrafi HTML giustificati;
- immagini locali centrate con testo alternativo;
- callout HTML con icone semantiche canoniche;
- `<details><summary>` per orientamento, riepiloghi, checkpoint e laboratori;
- diagrammi coerenti con `assets/tpsi5/visual-system/`.

Quando una lezione esistente viene revisionata, adeguare almeno tutte le sezioni toccate e verificare che la pagina resti coerente nel suo insieme. Non modificare il significato didattico solo per applicare la formattazione.

Le slide Marp non rientrano in questa regola di conversione HTML; devono restare compatibili con `scripts/build_slides.py`.
